# 12 — AI-Powered SaaS Feature

**Level:** 🐺 Wolf  
**Time:** 10–20 hours  
**Goal:** Take an existing project and add a meaningful AI feature. Ship it to real users.

---

## What You're Building

This one is open-ended on purpose. You pick an existing project — something you've already built or are building — and add an AI feature that makes it genuinely more useful.

This is where your full-stack background becomes your superpower.

---

## What You'll Learn

- Integrating AI into a production codebase (not a sandbox)
- Handling real user input — messy, unexpected, adversarial
- Rate limiting, error handling, and cost management for AI features
- What "good enough" looks like when real people use your product

---

## Ideas by App Type

| If you have... | AI feature to add |
|----------------|-------------------|
| A to-do app | Auto-categorize tasks, suggest priorities |
| A blog | Auto-generate SEO descriptions, suggest edits |
| A portfolio site | AI chatbot that answers questions about you |
| A notes app | Summarize notes, find connections between them |
| Nothing yet | Build an AI writing assistant (simple, high demand) |

---

## Approach

1. Pick an existing project (or start a simple one)
2. Identify ONE feature where AI adds real value
3. Build it with proper error handling and loading states
4. Deploy it and get at least one other person to use it
5. Watch how they use it. Fix what breaks.

---

## Done When

- [ ] AI feature is live in a deployed app
- [ ] At least one real user (not you) has used it
- [ ] Errors are handled gracefully — no raw API errors shown to users

---

## Stretch Goals

- Add usage limits per user (so you don't rack up API bills)
- Log AI usage and track which features are used most
- A/B test your AI feature against the non-AI version
