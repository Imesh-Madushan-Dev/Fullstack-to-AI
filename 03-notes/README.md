# Notes

Personal notes, lessons learned, and things that surprised you along the way.  
Write these as you go — future you will thank you.

---

## Suggested Format

Create one file per week or per project:

```
03-notes/
├── week-01.md
├── week-02.md
├── project-05-lessons.md
└── ...
```

---

## What to Write Down

- Things that confused you at first and how you figured them out
- Bugs that took more than 30 minutes to fix
- Prompts that worked surprisingly well (or badly)
- Concepts that finally "clicked"
- Ideas for future projects

---

## Template

```markdown
## Date: YYYY-MM-DD
## Project: 

### What I built

### What confused me

### What I figured out

### What I want to try next
```
